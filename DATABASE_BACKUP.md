# Резервная копия базы данных

Создание дампа из папки `backend`:

```bash
npm run db:backup
```

SQL-файл будет создан в `backend/backups`. Эта папка исключена из Git, потому что дамп может содержать персональные данные.

Для переноса проекта скопируйте SQL-файл на другой компьютер и восстановите его в MySQL:

```bash
mysql -u ИМЯ_ПОЛЬЗОВАТЕЛЯ -p < database-ДАТА.sql
```

После восстановления укажите параметры подключения к базе в `backend/.env`, установите зависимости и запустите backend.
